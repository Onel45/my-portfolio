OLEYO NELSON — Portfolio Website

FILES
- index.html: complete website code (HTML, CSS, JavaScript included)
- me.jpg: hero background photo
- leyo.jpg: portfolio design reference image used in the first project card

HOW TO RUN
1. Keep index.html, me.jpg, and leyo.jpg in the same folder.
2. Double-click index.html to open it in your browser.
3. To publish it, upload all three files to your web host.

CUSTOMIZE
- In index.html, search for your.email@example.com and replace it with your real email.
- Replace the LinkedIn, GitHub, and Instagram URLs with your profile links.
- Update the Skills and Projects sections as you complete real projects.

No build tools required. Google Fonts are loaded online; the site still works without them using fallback fonts.
